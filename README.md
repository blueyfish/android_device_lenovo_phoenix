Device configuration for Lenovo PHAB Plus / Yamada EveryPad3 (phoenix)
========================================================

The Lenovo PHAB Plus (codenamed _"phoenix"_) is a mid-range smartphone from Lenovo.
It was announced in September 2015.

## Device specifications

Basic   | Spec Sheet
-------:|:-------------------------
SoC     | Qualcomm® MSM8939 Snapdragon™ 615
CPU     | Octa-core (4x1.5 GHz ARM® Cortex™ A53 & 4x1.0 GHz ARM® Cortex™ A53)
GPU     | 550MHz Adreno™ 405
Memory  | 2 GB LPDDR3 RAM
Shipped Android Version | 5.0.2
Storage | 32 GB Samsung® Q4Z3MB eMCP
MicroSD | Up to 64 GB
Battery | Non-Removable Li-Ion 3500mAh battery
Dimensions | 186.6 x 96.6 x 7.6 mm
Display | 1080 x 1920 pixels, 6.8 inches (~324 ppi pixel density)
Rear Camera | 13 MP, f/2.2, autofocus, LED flash
Front Camera | 5 MP
